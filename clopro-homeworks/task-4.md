## Домашнее задание к занятию «Кластеры. Ресурсы под управлением облачных провайдеров»

### Цель работы

В рамках данного домашнего задания необходимо:
1. Развернуть отказоустойчивый кластер MySQL в приватных подсетях с использованием Terraform.
2. Развернуть региональный кластер Kubernetes в публичных подсетях с автомасштабированием и шифрованием через KMS.
3. Обеспечить связь между сервисами и проверить их работоспособность.

---

### 1. Кластер MySQL

- Созданы три приватные подсети в зонах `ru-central1-a`, `ru-central1-b`, `ru-central1-d`.
- Развёрнут кластер MySQL версии 8.0 с тремя хостами (по одному в каждой зоне).
- Использовано окружение **PRESTABLE**, платформа Intel Broadwell с 50% CPU (`b2.medium`), диск 20 ГБ.
- Настроено резервное копирование в 23:59 UTC.
- Включена защита от непреднамеренного удаления (`deletion_protection = true`).
- Создана база данных `netology_db` и пользователь с правами доступа.

---

### 2. Кластер Kubernetes

- Созданы три публичные подсети в зонах `ru-central1-a`, `ru-central1-b`, `ru-central1-d`.
- Создан сервисный аккаунт для K8s с ролями:
  - `k8s.clusters.agent`
  - `vpc.publicAdmin`
  - `container-registry.images.puller`
- Развёрнут региональный кластер Kubernetes с мастер-нодами в трёх зонах.
- Включено шифрование секретов через KMS (использован ключ из предыдущего ДЗ).
- Созданы три группы узлов (по одной на зону) с автомасштабированием от 1 до 2 узлов в каждой.

---

### 3. Проверка работоспособности

- Кластер MySQL доступен по внутренним IP-адресам хостов.
- Кластер Kubernetes доступен через `kubectl` (внутренний доступ через клиентскую ВМ).
- Подключение к БД `netology_db` через `web_sql` в консоли Yandex Cloud работает.

---

## Особенности реализации

| Параметр | Значение |
|----------|----------|
| **Окружение MySQL** | PRESTABLE |
| **Платформа MySQL** | Intel Broadwell, 50% CPU (`b2.medium`) |
| **Размер диска MySQL** | 20 ГБ |
| **Резервное копирование** | 23:59 UTC |
| **Защита от удаления** | Включена |
| **Зоны для MySQL** | ru-central1-a, ru-central1-b, ru-central1-d |
| **Зоны для K8s** | ru-central1-a, ru-central1-b, ru-central1-d |
| **Автомасштабирование K8s** | от 1 до 2 узлов в каждой зоне |
| **Шифрование секретов K8s** | KMS (ключ из ДЗ3) |

---

## Ресурсы Terraform

Основные файлы, относящиеся к этому заданию:
- `sql_mngd.tf` – кластер MySQL, база данных, пользователь.
- `k8s_mngd.tf` – кластер Kubernetes, группы узлов, сервисный аккаунт.
- `network.tf` – добавлены подсети для MySQL и K8s.
- `variables.tf` – переменные для MySQL (логин, пароль).
