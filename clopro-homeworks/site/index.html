🔐 Identity Access Management (IAM)

Централизованный сервис управления доступом к облачным ресурсам.

  • Users — аккаунты Яндекс, сервисные аккаунты, федеративные.
  • Groups — объединение пользователей (в т.ч. allAuthenticatedUsers, allUsers).
  • Polices — правила разрешений.
  • Roles — примитивные (admin, editor, viewer) и сервисные.
Пример Сервисный аккаунт storage-sa с ролью storage.admin для управления бакетами.

🔄 Single Sign-On (SSO)

Пользователь переходит из одной системы в другую без повторной аутентификации.

  • Единый административный интерфейс.
  • Поддержка SAML.
  • Быстрый доступ к нескольким аккаунтам и приложениям.

🗝️ Key Management Service (KMS)

Создание и управление ключами шифрования (Customer Master Keys).

  • Ключи генерируются внутри аппаратных модулей (HSM).
  • Не могут быть экспортированы.
  • Интеграция с Object Storage, Kubernetes, Certificate Manager.
  • Поддержка симметричных и асимметричных ключей.
В проекте Создан ключ bucket-encryption-key для шифрования бакета с картинками.

📦 Шифрование бакета S3

Объекты могут шифроваться:

  • На стороне клиента — до загрузки.
  • На лету — через SSL/TLS.
  • На стороне облака — SSE-S3, SSE-KMS, SSE-C.

В Yandex Cloud используется SSE-KMS.

Пример картинки, загруженной в бакет сайта (не зашифрован).

📜 Certificate Manager

Сервис получения и управления SSL/TLS-сертификатами.

  • Бесплатные сертификаты от Let's Encrypt.
  • Интеграция с Object Storage (HTTPS-хостинг), Application Load Balancer, API Gateway.
  • Централизованное управление и аудит.
Реализовано Получен сертификат для домена dubrovins.ru и поддоменов. Сайт доступен по HTTPS 🔒.
